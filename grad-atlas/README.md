# Grad Atlas application table

Static, evidence-led application-window UI. Date columns are primary, with individual intake/round/applicant scopes. Public relational SQLite is downloadable as a lossless gzip-compressed .sqlite.gz file (decompress before opening); table.json is its grouped web export.

## Files
- index.html, styles.css, app.js, model.js: interface
- data/table.json and data/programmes.sqlite.gz: generated by the relational data pipeline
- tests/model.test.js: date semantics, filtering and coverage tests

Run `npm test`. Serve over HTTP. Relative paths support a GitHub Pages subdirectory. The hardware/ link expects the existing hardware view to be retained alongside this interface.

A programme identity is provisional until semantic deduplication is complete. Missing dates remain visible. `not_published` is presented as not found in checked sources, not proof no date has been published. Annual rules never become inferred full calendar dates. A missing opening date never implies open applications. Calendar countdowns use a supplied timezone or UTC and cannot supply a missing cut-off time. Historical archive dates are not newly verified current dates.

No analytics, account sign-in, cookies, external libraries, fonts or assets are needed. Rendered values use textContent, not source-controlled HTML. Source links accept HTTP(S) only.

Exclude qa/ from public publication; it contains concept/reference images and verification notes, not site assets.
